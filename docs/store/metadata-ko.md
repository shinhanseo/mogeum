# 모금 · 스토어 문안 초안

게시하지 않은 검토용 문안이다. 앱 이름 사용 가능 여부, 연령 등급, 개인정보 설문 및 최종 제출은 별도 확인한다. 실제 스크린샷은 현재 베타 빌드에서 촬영한 화면만 사용한다.

## 기본 정보

- 앱 이름 후보: 모금 — 한 잔 기록
- 부제: 한 모금씩, 쌓이는 내 취향
- 짧은 소개: 사진으로 남기고, 질문으로 완성하는 나만의 술 기록.
- 카테고리 후보: 음식 및 음료
- 대상: 성인 사용자. 연령 등급은 각 스토어 질문에 실제 기능대로 답한 결과를 따른다.

## 상세 설명

한 모금씩, 쌓이는 내 취향.

마셨던 술은 기억하고 싶은데, 테이스팅 노트는 어디서부터 써야 할지 어려웠나요? 모금은 위스키·와인·맥주·전통주를 한곳에 모으는 개인 기록장입니다.

사진 한 장부터 남겨보세요.
사진만 저장해도 한 잔의 기록이 됩니다. 이름, 마신 날, 다시 마시고 싶은지와 선택적인 별점을 더할 수 있어요. 같은 술을 다시 마셨다면 날짜별 경험으로 이어 남겨요.

빈 메모장 대신 질문에 답해요.
가볍게 남기기와 자세히 남기기 중 그날에 맞는 방식을 골라요. 주종에 맞춰 향과 맛, 질감과 여운을 선택하면 답한 느낌을 문장으로 정리해줘요. 모르는 질문은 건너뛰고, 완성된 문장도 내 말로 고칠 수 있어요.

쌓인 기록에서 내 취향을 살펴봐요.
직접 남긴 감각과 선호를 바탕으로 AI 취향 요약을 확인해요. 왜 그렇게 정리했는지 근거가 된 기록도 함께 볼 수 있어요. 사진만 있는 기록으로 맛을 추정하거나 적은 기록을 전체 취향으로 단정하지 않아요.

다음 한 잔을 찾아봐요.
출처가 있는 제품 특징과 좋게 남긴 기록을 비교해 새로운 술을 살펴봐요. 닮은 점뿐 아니라 다른 점도 확인하고, 마셔보고 싶은 술은 따로 저장해요.

메뉴판 앞에서도 내 기록을 활용해요.
메뉴판 사진을 최대 5장까지 모아 기기에서 글자를 읽고, 이름·가격·용량을 확인한 뒤 취향과 비교해요. 제품이 확실하지 않으면 확인 후보로 구분해요. 인식 결과와 추천은 실제 메뉴·직접 느낀 감각과 다를 수 있어요.

모금은 개인 기록 서비스입니다. 술을 판매하거나 주문·결제를 중개하지 않습니다.

## 검색어 초안

술기록,테이스팅노트,위스키,와인,맥주,전통주,취향,술장,메뉴판

## 스크린샷 순서와 문구

1. 술장: 한 모금씩, 쌓이는 내 취향
2. 사진/기본 기록: 사진 한 장부터 남겨요
3. 질문 → 문장 결과: 고른 느낌이 나만의 노트로
4. 가볍게/자세히 선택: 오늘은 원하는 만큼만
5. AI 요약과 근거: 내 기록에서 발견한 취향
6. 다음 한 잔과 이유: 닮은 점도, 새로운 점도
7. 여러 장 메뉴판/확인/추천: 메뉴판에서도 내 취향 찾기

개발 배너·테스트 문구·다른 사람의 개인정보·실제 세션이나 비밀키가 나오지 않게 한다. 실험용 fixture는 필요한 경우 예시임을 명시한다. 아직 검증하지 않은 기능을 완성된 화면처럼 꾸미지 않는다.

## 심사 메모 초안

- 로그인은 Apple/Kakao를 사용한다. 심사용 별도 계정/접근 방법은 준비 후 비공개 심사 메모에 등록한다. 실제 계정 자격증명을 이 저장소에 넣지 않는다.
- 사진/카메라는 술 기록 및 메뉴판 촬영을 위해 요청한다. 마이크는 사용하지 않는다.
- 메뉴판 OCR은 기기에서 실행하고 읽은 텍스트/좌표를 서버로 전송한다. 취향 요약 provider에는 파생된 감각 특징과 집계만 전송한다. 세부 내용은 data-inventory 참조.
- 앱 내 계정 삭제 경로가 있다. 실제 소셜 grant 해제는 별도 테스트 계정 검증이 남아 있다.
- 인앱 구매/술 판매/공개 사용자 피드는 현재 범위에 없다.

## 제출 전 남은 입력

실제 개인정보 처리방침/약관 URL, 지원 URL·문의처, 저작권 표시 주체, 심사 연락처·별도 계정, 최종 연령/개인정보 설문, 실제 기기별 스크린샷, iOS 서명/스토어 업로드가 필요하다. 내용을 추측해 채우거나 최종 동의를 자동으로 제출하지 않는다.
