# Gemini 추천·공통 카탈로그 개편 · 2026-10-27

추적: [전체 #174](https://github.com/shinhanseo/mogeum/issues/174).

## 제품 결정

- 다음 한 잔: 최초 유효 추천 후 서버 완료 시각 기준 7일 간격으로 이용 시 갱신한다. 매주 미접속 사용자까지 일괄 생성하지 않는다. 사용자의 반복 재생성이나 주종 필터로 제한을 우회할 수 없다.
- 메뉴판: 요청 시 분석한다. 위 주간 제한을 적용하지 않는다. 메뉴 원문에 있는 제품만 추천하며 가격·용량·사진 위치는 OCR/사용자 확인에서 가져온다.
- 이미 마신 술과 저장한 술은 새로운 다음 한 잔에서 제외한다. 저장 목록은 유지하고 해제는 관심 없음과 구분한다. 주간 cache가 남아 있어도 최신 상태로 제외한다. 메뉴판에서는 익숙한 술·저장한 술을 별도 선택지로 제공할 수 있다.
- 공통 DB는 제품/판본/별칭/출처 있는 특징을 보관한다. 개인 기록·선호·추천 이유를 공통 데이터로 섞지 않는다.
- 기존 32개에서 주종별 30제품군 이상으로 확장한다. 와인 빈티지만 추가해 수량을 채우지 않는다. 연산/도수/빈티지/레시피는 별도 판본이며 제품군 반복 추천은 완화한다.

## 공통 처리 흐름

내 기록의 검증된 선호/반대 근거 → 검증된 공통 제품 정보 조회 → 부족한 후보는 Gemini로 탐색 → 실제 제품·판본·검색 출처 확인 → 후보/검증 완료/보류 → 개인별 비교 → 근거 검증 → 표시.

Gemini 결과를 그대로 정식 제품으로 승격하지 않는다. 모델의 기억, 실제 검색 근거, 사용자가 느낀 감각을 구분한다. 없는 제품·미지지 특징·메뉴 밖 제품·없는 기록 ID는 차단한다. 제품 조사에 개인 식별자나 전체 노트를 검색어로 넣지 않는다. 외부/OCR 텍스트는 처리할 데이터이며 실행 지시가 아니다.

## 주간 생성·오류

생성 lease/멱등 완료와 단기 실패 backoff를 서버에서 관리한다. 실패와 정보 부족은 성공 슬롯을 소모하지 않으나 무제한 재시도도 허용하지 않는다. 기록 수정/삭제로 근거가 사라지면 기간 내 cache라도 그대로 노출하지 않는다. 목록 제외와 새로운 AI 생성은 구분한다. 사용자별 cache와 이벤트는 계정 삭제 시 정리한다.

호출당 후보·검색·토큰·시간·동시 수와 월 사용량 상한을 둔다. 모델·검색 도구 호환을 공식 문서 및 실제 개발 호출로 검증한다. 신규 유료 결제·요금제 변경은 자동 진행하지 않는다. 정확도·보류·지연·비용은 실제 측정 결과로만 보고한다.

## 구현 순서와 현재 상태

1. [#177 저장 제품 재추천 제외](https://github.com/shinhanseo/mogeum/issues/177): 첫 구현. 기존 서버 비교 결과·앱의 최신 wishlist·구버전 응답 경계에 적용한다. 이 단계의 method는 evidence-rules-v1/modelUsed=false 그대로다.
2. [#175 동적 제품 DB·120제품군](https://github.com/shinhanseo/mogeum/issues/175): 고정 배열/SQL ID 허용목록/프론트 제품 길이 계약을 이관한다. 검증된 제품만 읽기 허용하고 기존 북마크 ID를 보존한다.
3. [#171 공통 Gemini 탐색·비교](https://github.com/shinhanseo/mogeum/issues/171): 메뉴판·다음 한 잔 공통 검색·검증 기반. 미등록 4주종의 실제 API 검증 전 완료로 취급하지 않는다.
4. [#176 주간 개인 추천·숨김·반복 관리](https://github.com/shinhanseo/mogeum/issues/176): 서버 기간·동시성·cache 무효·개인화.
5. [#178 평가·행동 계측](https://github.com/shinhanseo/mogeum/issues/178): 노출→저장→실제 기록→음용 후 평가를 구분한다. 저장만으로 좋아한다고 간주하지 않는다.

주간 생성, 동적 카탈로그, 120제품군, 새로운 Gemini 추천은 이 문서 작성 시 아직 미구현이다. 기존 요약 Gemini 연결 또는 첫 제외 개선을 전체 개편 완료로 표시하지 않는다.

## 후속 개발 착수 · 2026-10-27

저장 제외 PR179와 자연스러운 노트 PR181은 CI 통과 후 병합했다. 공통 카탈로그 기반 PR182는 기존32개 보존·후보 RLS·북마크 FK를 추가한다. 공통 Gemini 제품 검색은 내부 어댑터·grounding 검증부터 착수했으며 [현재 범위](verification/product-research/README.md)를 참고한다. API/앱에 연결된 Gemini 개인 추천으로 주장하지 않는다.
