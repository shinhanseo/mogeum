## 에셋과 구현

모구는 물방울 몸·사진 주머니가 있는 버건디 앞치마 캐릭터. 사용 가능한 Figma 벡터 원본을 추출해 사용하고 임의의 새 캐릭터로 바꾸지 않는다. 현재 저장소에는 주종 일러스트 4종만 있다. 모구·제품 사진은 아직 앱용으로 반출하지 않았으며 별도 이슈에서 원본과 사용 범위를 확인한다.

사진 없는 술은 assets/illustrations의 고정 SVG를 사용한다. 실제 병이나 라벨처럼 생성해 오인시키지 않는다. 사용자 사진은 원본 비율에 맞게 crop하고 사진만 저장한 상세와 노트 상세를 구분한다. 첫 기록 진입, 질문 skip, 뒤로 가기, 완료, 수정 취소, 키보드, 로딩, 빈 상태, 오류 상태를 포함한다. 프레임 설명은 개발 문서이며 제품 화면에 그대로 붙이지 않는다.

## 반복 음용 구현 · 2026-10-22

04의 19(4:4227) 재음용 행동과 기존 11/평가 화면을 재사용한다. 이름·주종만 미리 채운 기존 정보 폼에서 시작하며 사진이 없으면 `사진 추가`로 표시한다. 18 사진 기록의 기본 CTA는 노트 추가, 19 노트 기록의 기본 CTA는 한 번 더 기록하기로 유지하고, 다른 행동은 공통 text 버튼으로 분리했다. 두 번째 text 행동과 반복 기록 안내 문구는 구현 확장 상태이며 원본 픽셀 일치로 주장하지 않는다. 술장 다회 기록은 기존 카드 분류 아래와 같은 타이포로 `기록 N회`를 표시한다. 근거 원본 측정은 docs/verification/figma-reference/detail.json, record-info.svg, record-rating.svg.

## 취향 요약 구현 · 2026-10-23

## Galaxy QA 보완 · 2026-10-27 · #165

사용자 추가 요청에 따라 술장 이름의 고정 두 줄 예약 높이를 제거한다. 한 줄은 한 줄 높이, 긴 이름은 최대 두 줄이며 이름→주종은 기존 4pt 간격으로 이어진다. 카드 아래를 같은 선반에 맞추고 사진은 기존 3:4 비율을 유지한다.

내 취향의 초기·요약·갱신 상태는 기존 색상/타이포/간격 토큰과 모구 원본을 사용하되, 요약/상태/기록 수를 하나의 영역에 모은다. 근거 사진은 세로 3:4 썸네일과 기록 정보로 보여주고 다음 한 잔·메뉴판 진입은 두 개의 목록형 행동으로 정리한다. 이는 사용자의 새 디자인 요청에 따른 확장안이다. 이번 Figma 재조회는 인증 오류로 실패하여 최신 Figma와 픽셀 단위 일치를 확인했다는 의미가 아니다. 기존 보관 원본 `docs/verification/figma-reference/` 및 기존 토큰을 기준으로 한다.

주종 일러스트는 `assets/discovery`의 Figma 원본 SVG를 변경하지 않고 로컬 XML로 읽는다. Android `asset:/`를 HTTP fetch에 맡기지 않는다. 추천은 출처 있는 제품 카탈로그와 실제 느낌 기록 비교이며 Gemini 실시간 제품 검색으로 표시하지 않는다.


## 삭제 진입 수정 · 2026-10-27 · #172

사용자 요청으로 술장 카드의 ⋯ 버튼과 길게 누르기 관리 진입을 제거한다. 술장은 사진·이름·주종만 표시한다. 사진 탭 → 상세 → 수정·삭제 → 날짜별 기록 삭제 또는 이 술의 전체 기록 삭제로 이어지며, 전체 삭제는 서버의 최신 연결 기록 수를 읽은 확인 화면으로 바로 진입한다. 삭제 RPC와 충돌/재시도 보호는 유지한다.

## 저장한 술 재추천 제외 · #177

기존 다음 한 잔(19:784)·저장 목록(19:972)의 컴포넌트와 크기는 유지한다. 저장 성공 후 최신 wishlist를 사용해 해당 카드를 새 추천에서 숨긴다. 후보 소진 시 기존 빈 상태의 문구만 “새롭게 추천할 술이 아직 없어요.”와 마신 술/저장한 술 제외 안내로 조정한다. 이 빈 상태 문구는 사용자 최신 규칙의 확장 상태이며 Figma 픽셀 일치 검증으로 주장하지 않는다.
