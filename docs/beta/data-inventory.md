# 실제 데이터 처리 내역 · 소유자 문서 검토용

이 문서는 코드와 현재 개발 서버 동작을 정리한 기술 자료다. 게시할 개인정보 처리방침/약관 자체가 아니며, 책임자/문의처/보유 정책은 소유자가 확정해야 한다. 실제 문서가 게시되기 전 외부 배포 gate는 실패한다.

| 데이터 | 현재 처리 | 확인/결정할 사항 |
|---|---|---|
| Apple/Kakao 로그인 identity·계정 ID | Supabase Auth로 로그인하고 서버에서 JWT 검증 | 실제 로그인 동의 항목과 제공자 정책 확인 |
| 기록 사진·이름·날짜·빈티지·평가·감각·메모 | 계정별 DB와 비공개 Storage. 사진은 만료 URL로 제공 | 보관 기간·백업/복구 정책·문의처 확정 |
| 작성 중 초안 | 기기의 앱 전용 저장소. 계정별 분리 | 서버에 저장되지 않은 초안의 유실/삭제 안내 |
| provider refresh token | 기기 SecureStore로 보관 요청, 서버에서 subject/app 검증 후 AES-GCM 암호화 | 실제 외부 연결 해제 검증. 원문 키/토큰은 일반 사용자에게 제공하지 않음 |
| Supabase 로그인 세션 | 앱 전용 세션 저장소에 복원용으로 보관 | 모든 세션이 SecureStore에 저장된다고 고지하지 말 것 |
| 메뉴판 이미지 | 기기에서 OCR. 원본 메뉴 이미지는 현재 서버로 업로드하지 않음 | 실제 사진에 포함되는 제3자 정보와 접근 권한 안내 |
| OCR 텍스트·좌표·확인 메뉴 | Supabase 함수로 보내 해석/추천. 확정 세션은 계정 DB에 저장 | 서버 보관·계정 삭제 동작 확인 |
| AI 취향 요약 | Gemini에는 계산된 특징 ID/라벨·기록 수·긍정/상반된 개수만 보냄 | Google 서비스 데이터 정책·처리 위치/위탁·국외 처리 고지 검토 |
| 사진·계정 ID·원문 메모 | 현재 요약 provider 프롬프트에는 포함하지 않음 | 구현 변경 시 이 자료도 갱신 |
| 누끼 이미지 | 기기 내 Apple Vision/ML Kit, 계정별 로컬 캐시 | 기기 변경 시 미동기화, 모델 다운로드/OS 제약 |
| 삭제 영수증 | 사용자 UUID·제출 JWT 해시·진행 상태. 완료 응답 재확인은30일 | 오래된 완료 영수증은 후속 삭제 시작 시 정리. 정기 청소/정확한 보유 정책 확정 필요 |
| 공개 GitHub 피드백 | 테스터가 직접 이슈로 제출 | 개인 사진·비밀번호·토큰을 보내지 않도록 안내 |

현재 별도 광고/사용 행동 분석 SDK를 추가하지 않았다. OS·TestFlight·빌드 서비스의 진단 처리는 각각의 설정과 정책을 별도로 확인해야 한다. Supabase 개발 프로젝트와 서버 키, EAS 서명 자료는 비공개 설정에 보관하며 앱에 service role/AI 키를 넣지 않는다.
