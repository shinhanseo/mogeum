# 모금 내부 QA 안내

한 모금씩, 쌓이는 내 취향.

이 빌드는 출시 전 동작 확인용이다. 설치 링크와 앱 버전/빌드 번호는 운영자가 별도로 전달한다. Android는 APK를 설치하고, iOS 시뮬레이터 앱은 Mac에서만 사용한다. 실제 iPhone용/TestFlight 빌드와 혼동하지 않는다.

## 10분 확인 순서

1. Apple 또는 카카오로 로그인하고 앱을 종료했다 다시 열어 술장이 유지되는지 본다.
2. 사진·술 이름·간단한 감상을 저장한다. 이 단계만으로도 기록은 완성이다.
3. 같은 술을 한 번 더 기록해 술장 한 칸에 날짜별 경험이 모이는지 본다.
4. 가볍게 또는 자세히 노트를 작성한다. 모르겠는 질문은 건너뛰고, 완성 문장이 실제 선택한 감각과 맞는지 본다.
5. 기록 수정·사진 교체 후 술장과 상세에 반영되는지 본다.
6. 느낌 기록이 쌓이면 내 취향 요약과 다음 한 잔의 근거를 확인한다. 사진만 저장한 기록은 감각 취향의 근거가 아니다.
7. 메뉴판 2장을 올려 이름·가격·잔/병 용량을 확인하고 수정한 뒤 추천을 요청한다. 모호한 가격은 직접 확인한다.
8. 잠깐 네트워크를 끊고 다시 연결했을 때 작성 내용이 보존되고 재시도가 가능한지 본다.

계정 삭제는 되돌릴 수 없다. 운영자와 합의한 삭제용 계정에서만 시험하고 평소 사용하는 계정으로 수행하지 않는다.

## 피드백

[베타 피드백 작성](https://github.com/shinhanseo/mogeum/issues/new?template=beta-feedback.yml). 이 저장소의 이슈는 공개다. 기기 종류/OS, 앱 빌드 번호, 눌렀던 순서, 기대한 결과와 실제 결과를 적는다. 스크린샷은 선택이며 계정·개인 기록을 가린다. 비밀번호·인증 코드·세션 토큰은 첨부하지 않는다.

## 현재 제한

- 추천은 출처가 확인된 제한된 제품 카탈로그 안에서 비교한다. 모든 술/모든 맛을 아는 서비스가 아니다.
- OCR은 오탈자나 가격 연결을 틀릴 수 있어 확인 화면이 필요하다. 실제 저조도 매장 사진의 품질 평가는 진행 중이다.
- 누끼는 기기 로컬 표시다. 다른 기기에 동기화되지 않으며 투명 잔 안 배경이 남을 수 있다.
- iOS Simulator에서는 Apple Vision 누끼가 동작하지 않는다. 실제 iPhone 확인이 필요하다.
- 실제 Apple/Kakao 계정의 연결 해제 전체 검증은 아직 남아 있다.
