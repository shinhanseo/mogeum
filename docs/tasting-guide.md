# 질문형 노트 기본안

기존 Figma의 작성 화면 문구를 우선한다. 아래는 주종별 구현·데이터 정규화를 위한 기본안이며 실제 화면과 차이가 있으면 확인 후 한곳을 기준으로 갱신한다. 사진만 저장하는 경로에서는 질문을 강제하지 않는다. 한 화면 한 질문, 최대 2–3개 선택, 건너뛰기·이전 답 유지·선택 취소를 제공한다. 전문 표현보다 일상어를 사용한다.

| 주종 | 향 예시 | 맛 예시 | 마무리 예시 | 질감/도수감 예시 |
|---|---|---|---|---|
| 위스키 | 과일, 꿀·바닐라, 나무, 견과류, 연기, 잘 모르겠어요 | 달게, 드라이하게, 쌉싸름하게, 매콤하게 | 금방 사라져요, 오래 남아요, 깔끔해요, 알싸해요 | 가벼워요/묵직해요, 부드러워요/알코올이 강해요 |
| 와인 | 과일, 꽃, 나무, 향신료, 잘 모르겠어요 | 달아요, 달지 않아요, 새콤해요, 떫어요 | 산뜻해요, 오래 남아요, 떫음이 남아요 | 가벼워요/묵직해요, 탄산이 있어요 |
| 맥주 | 과일·시트러스, 꽃·풀, 빵·곡물, 커피·초콜릿 | 상큼해요, 고소해요, 쌉싸름해요, 달아요 | 깔끔해요, 쓴맛이 남아요, 구수해요 | 가벼워요/진해요, 탄산이 약해요/강해요 |
| 전통주 | 쌀·곡물, 과일, 꽃, 고소한 향 | 달아요, 새콤해요, 구수해요, 드라이해요 | 깔끔해요, 달게 남아요, 알싸해요 | 맑고 가벼워요/걸쭉해요, 탄산이 있어요, 도수가 느껴져요 |

마지막 공통 질문: **이 술, 다시 마시고 싶나요?** `또 마시고 싶어요 / 상황에 따라요 / 다른 걸 마실래요`. 질문 전체를 생략한 경우 null이다. 선택을 안 했다는 것을 싫어한다고 저장하지 않는다.

선택적으로 기존에 고른 특징에서 좋거나 아쉬웠던 것을 짚고 한 줄 메모를 쓴다. 특징을 선택했다는 것만으로 좋아한다고 추론하지 않는다. AI가 노트 문장을 정리하는 기능을 붙일 경우 사용자 확인 후 저장하고, 답하지 않은 특징을 보충하지 않는다. 직접 쓴 문장을 확인 없이 덮어쓰지 않는다.

내부 저장은 descriptor_code와 question/schema version을 사용한다. 한국어 표시 문구를 PK처럼 쓰지 않는다. note 자체는 사용자 원문이며 원래 선택값도 보존한다.
