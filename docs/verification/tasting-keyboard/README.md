# 테이스팅 입력창 키보드 가림 수정

질문 자유 입력·다른 향 입력·문장 직접 수정에 동일하게 적용한다.

- 키보드 회피 컨테이너를 iOS padding / Android height로 설정하고 safe-area top을 offset으로 전달한다. ScrollView를 flex:1로 제한해 줄어든 viewport 안에서 실제 스크롤이 가능하게 한다.
- 키보드 표시/프레임 변경·viewport 변경·입력 크기/선택 변경 시 포커스한 입력창을 측정해 키보드 위16px까지 스크롤한다.
- Done은 blurAndSubmit 후 키보드만 닫는다. keyboardDidHide까지 원래 스크롤 위치를 보존해 닫힌 뒤 복원한다. 질문 이동은 기존처럼 원점을 해제하고 새 질문 위로 이동한다.

검증: 타입·린트·테이스팅 계약·단위419통과/환경12제외. 실제 키보드 애니메이션·긴 입력·커서 이동·확대 글자·작은 화면의 iOS/Android 네이티브 확인은 아직 남아 있다. 현재 USB 기기 미연결이며 새 앱 빌드/설치는 하지 않았다. 화면 디자인 토큰·질문·저장 계약은 변경하지 않는다.
