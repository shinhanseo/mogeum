# 계정 동작 구현 진행

내 취향 하단의 계정 관리 → 계정 화면 → 로그아웃 확인 → 이 기기의 Supabase 세션 종료 경로를 추가했다. 기존 공통 ScreenHeader/Button과 디자인 토큰을 재사용했다. 계정 화면은 원본에 없는 추가 상태이며 Figma와 동일한 프레임으로 검증했다고 주장하지 않는다.

로그아웃은 scope=local로 이 기기의 로그인만 종료한다. 서버 기록·비공개 사진·계정별 초안은 삭제하지 않는다. SDK auth 변경 이벤트가 기존 보호 route들을 로그인 화면으로 전환한다. 네트워크/SDK 실패는 성공으로 숨기지 않으며 재시도한다. 호출 전 계정 ID가 달라지면 새 계정을 로그아웃하지 않는다. 중복 요청은 같은 Promise를 공유한다.

`/dev/account?failure=1`은 실제 세션을 변경하지 않는 명시적 UI fixture다. iOS dev build에서 확인→오류→재시도 버튼 유지 상태를 확인했다. 실제 사용자가 막 로그인한 카카오 계정을 임의로 로그아웃하지 않았다. 계정 삭제·기기 데이터 정리는 이어지는 작업이며 이 문서로 완료 처리하지 않는다.

단위 회귀는 중복 요청 1회, 다른 계정으로 전환되면 원격 로그아웃 0회, 실패 후 재시도를 검사한다. `npm run check`: 295개 중 289 pass, 별도 환경 의존 6 skip. [iOS 실패 fixture](ios-logout-failure-fixture.png). 실제 OAuth·원격 logout endpoint를 통한 로그아웃은 아직 추가 검증이 필요하다.
