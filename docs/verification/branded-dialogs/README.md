# 공통 확인 모달

앱의 기본 Alert 6곳을 화면 소유 useConfirmDialog로 교체했다. 크림 surface, 버건디 primary, rose 강조, 공통 Button/타이포/간격/radius를 사용한다. 기존 화면 디자인 토큰에 맞춘 신규 모달이며 Figma에 동일 원본 프레임이 있거나 픽셀 일치 검증을 완료했다고 주장하지 않는다.

적용: 기록 수정 취소, 저장 전 변경 취소 후 이동, 날짜별 기록 삭제, 사진/이동 수정 취소, 기록 이동 확정, 수동 편집 노트 유지/재생성.

- 실수로 연타해도 한 번만 실행한다. 표시 중 두 번째 요청은 덮어쓰지 않는다.
- Android Back·바깥 영역·접근성 escape는 닫기/명시적 cancel만 수행하며 파괴 동작을 실행하지 않는다. 노트 재생성 선택은 바깥을 누르면 기존 화면을 유지한다.
- 화면을 떠나면 해당 모달/콜백도 함께 해제된다. 다른 계정이나 화면에 전역 확인 요청을 남기지 않는다.
- 긴 설명·확대 글자는 본문 ScrollView와 최대 높이로 처리하며 버튼은 별도 영역이다. 중앙 정렬 버튼은 공통 Button을 그대로 사용한다.
- OS 카메라/사진 권한창은 시스템 UI를 유지한다. 기존 사전 권한 안내와 계정 삭제 전용 확인 화면은 유지한다.

개발용 `/dev/dialogs`에서 삭제·취소·문장 선택을 실제 삭제 없이 확인할 수 있다. production에서는 접근하지 못한다.

타입·린트·계약/단위 검사 결과는 PR에 기록한다. 네이티브 화면/스크린리더/Android Back 실제 확인과 설치는 아직 수행하지 않았다.
