# 메뉴판·취향 화면 잔여 수정 · 2026-11-01

메뉴판 단계가 바뀌면 다음 animation frame에 ScrollView를 최상단으로 이동한다. 이전 읽은 메뉴/결과 화면의 스크롤이 새 화면에 남아 제목을 가리지 않게 한다. 단계가 바뀌거나 unmount되면 예약 frame을 취소한다.

내 취향 통계는 라벨·숫자·단위를 하나의 중첩 Text가 아닌 baseline View로 나눠 숫자에 title 토큰의 lineHeight와 Android font padding을 적용한다. 각 통계는 하나의 접근성 라벨로 읽힌다. 기존 큰 글자 세로 배치는 유지한다.

사용자가 최신 기기 화면을 확인하고 머지를 요청한 잔여 코드다. 이 수정은 앞선 iPhone Release 빌드에 포함돼 있었다. 현재 세션의 Device Hub는 iOS26.6 실기기 스트리밍을 지원하지 않아 직접 화면 육안 재검증은 하지 않았다.

npm run check: 타입/린트 오류 없음, 전체 테스트462통과·14환경 제외. 새 기능이나 디자인 시스템 변경은 없다.
