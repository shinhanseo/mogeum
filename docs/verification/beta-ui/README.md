# iOS 내부 베타 둘러보기 QA · 2026-10-26

Device Hub가 제공하는 iPhone 17 Pro / iOS 26.5 화면을 CUA로 직접 조작했다. 검사 대상은 최초 Simulator Release 빌드이며, 최신 법적 문서 링크를 포함한 후속 빌드와는 구분한다. 실제 사용자 로그인/기록을 열거나 변경하지 않았다.

확인한 동작:

- 로그인 화면의 모구·두 소셜 버튼·둘러보기·하단 안내를 확인.
- 둘러보기 → 빈 술장: 5개 주종 칩이 한 줄이고 가운데 + 및 하트 상단이 잘리지 않음.
- 내 취향: 기록 없는 안내가 표시되고 임의 추천 제품 목록이 나오지 않음.
- 비로그인 상태의 다음 한 잔/중앙 기록 버튼은 로그인 화면으로 연결.
- 술 찾기에서 긴 한글 검색어가 입력됨. 키보드와 검색 필드가 겹치지 않음. Return으로 키보드 종료, 검색어 정리 및 검색 닫기 후 기본 술장 복귀.

폰트 확대/다른 작은 기기/실제 로그인 뒤 전체 흐름/최신 Figma 같은 크기 pixel 비교는 이 검사에 포함하지 않는다. 화면 캡처는 QA 증거이며 검색 테스트 문구·기기 도구 테두리를 포함한다. 스토어 홍보 이미지로 사용하지 않는다.

## 후속 Simulator Release 확인

법적 문서 연결을 포함한 후속 빌드도 다운로드·Hermes 번들 검사·설치/실행했다. 접근성 트리에 약관/개인정보 링크 2개가 각각 노출되고 각 링크를 누르면 실제 URL 미설정 안내가 표시됨을 확인했다. [미설정 안내 캡처](ios-legal-unconfigured.png). 정상 게시 주소 열기는 아직 확인하지 않았다.
