# 메뉴판 미등록 술 실시간 조사·비교 · #171

앱 MenuFlow가 menu-research-v1을 전송한다. 서버는 인증 사용자 ID로 기존 메뉴 lease/하루10회 제한을 예약하고, 최대2개 미등록 메뉴 이름만 Gemini 식별에 사용한다. 연산/도수/빈티지 숫자가 소실되거나 새로 붙으면 거부한다. 식별과 제품 검색 모두 공유 조사 캐시·일20회/월200회 제한·backoff를 적용한다. 개인 취향/메모/사진/OCR 전체 원문은 검색 모델에 보내지 않는다.

제조사 출처를 원문 재조회해 제품명과 특징 인용을 대조한다. 같은 연산의 Year Old/Year Whisky 표기만 정규화하고 다른 연산·캐스크 스트렝스는 합치지 않는다. 원문 NOSE/PALATE/FINISH의 명시적 단어에 한해 닫힌 어휘표로 추출을 보완한다. 부정/비교 문장·일반 소개는 제외한다. 후보를 verified로 자동 승격하지 않고 이번 메뉴 응답에만 문서/ID를 포함한다.

결과/근거 화면은 기존 컴포넌트와 토큰을 유지하며 ‘검색으로 찾은 제품 후보’, 후보 제품명·제조사 링크·실제 메뉴 판본 확인 안내를 표시한다. 조사 실패/미확정/횟수 초과/2개 초과 상태는 기존 제품 비교와 함께 표시한다. 이미지가 없는 후보는 기존 주종 일러스트를 쓴다. 후보 ID를 입력 메뉴나 북마크에 저장하지 않는다.

## 실제 검증 · 2026-10-31

- 개발 DB에 없는 부나하벤18년 + 기존 글렌리벳12년 + 가짜 합성 술 메뉴를 실제 로그인 임시 계정으로 전송했다.
- 부나하벤18년이 제조사 원문을 대조한 세션 제품 후보로 반환됐다. 기록0개에서는 전부 score0, 감각 기록 작성 후 새 후보가 실제 근거 양수 점수로 비교됐고 같은 요청은 캐시 결과를 재사용했다. 가짜 술은 unresolved/unverified를 유지했다.
- 기존 요청 형식도 정상 처리됐다. 임시 계정은 finally에서 삭제했다. 자동 공통 카탈로그 등록은 하지 않는다.
- `scripts/verify-managed-live-menu-research.ts`는 명시적 개발 opt-in과 실제 provider/DB를 사용한다. 합성 개발 시안은 `app/dev/menu-research.tsx`이며 별도 서버 호출이 없다.
- npm check461통과/환경14제외. 연구/선택 SDK transport17개 통과. 후보 탈취·알려진 제품 대체·가짜 출처·숫자 판본 변경·한도에서 무호출·실패 lease 정리·실제 감각 없이 추천하지 않는 검증 포함.

## 한계

첫2개 미등록 메뉴만 조사한다. 승인된 제조사 origin의 확인 가능한 원문이 없거나 제품이 모호하면 추천으로 확정하지 않는다. 검색 후보의 원문 인용 일치는 판본/감각 의미의 완전한 자동 검증을 보장하지 않으며 실제 메뉴와 동일한지 확인 안내를 유지한다. 시뮬레이터 UI 제어는 Device Hub 접근 시간 초과로 확인하지 못했으며 실기기 검증으로 표시하지 않는다. React 검토 가이드에 따라 파생 상태·기존 epoch 취소·조건부 렌더링·긴 로딩 문구 줄바꿈을 점검했다. Figma의 새 화면을 생성하거나 새 수치를 임의로 변경하지 않았다.
