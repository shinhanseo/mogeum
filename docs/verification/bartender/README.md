## 실제 조사 경계

부나하벤 18년 명시적 조사 요청은 모델의 조사 제안과 사용자의 별도 실행을 거쳐 제조사 원문 검증 미통과(`unresolved`)로 끝났다. 이 제품의 실제 검색 추천 성공을 주장하지 않는다. 검증 미통과 시 카드/맛 특징을 생성하지 않는 경로는 확인했다. 다른 제품·주종의 실검색 성공 범위는 추가 QA가 필요하다.

## 일반 대화 전환 · 2026-11-05

현재 발화가 일상 대화이면 모델 intent를 conversation으로 받고 서버가 후보·조사 제안을 제거하며 오늘의 조건을 보존한다. 화면은 가장 최근 응답에 추천 카드가 있을 때만 술 조정 선택지를 노출한다. 친구를 만난 일상 이야기로 전환한 실제 Gemini 응답에서 추천 없음·조건 보존을 확인했다. 대화 중 로딩과 입력 안내도 일반 대화 문구로 수정했다.

## 맥주 조건·안주 대화 맥락 · 2026-11-05

모델 입력에 최근 추천의 제품명·판본과 대화 주제를 포함했다. 안주 요청은 pairing으로 분류해 술 후보/조사를 억제하고, 사용자가 선택을 맡기면 구체적인 음식을 제안한다. dark 스타일과 최소 도수를 오늘 조건에 보관하며 서버는 제품 설명의 흑맥주/스타우트/포터 표기와 판본의 %를 확인한다. 확인할 수 없는 제품은 해당 조건 추천에서 제외한다. ‘높은 도수’만 주어지면 수치 기준을 묻게 하며 임의 기준을 정하지 않는다.

관리형 합성 계정의 실제 연속 대화에서 시원한 맥주 → 8% 이상 흑맥주 → 안주 → 안주 선택 위임을 확인했다. 흑맥주·도수 조건이 확인되지 않은 후보는 숨겼고 안주 두 응답에는 새 맥주 카드가 없었다. 듀벨이 흑맥주 조건을 통과하지 않도록 별도 도메인 회귀 검증을 추가했다.

## 다회 대화 QA · 2026-11-05

`scripts/qa-bartender-conversations.ts`로 실제 개발 서버/Gemini와 합성 사용자 대화를 반복했다. 맥주 조건·안주, 잡담→와인→맥주, 위임·예산·저녁, 일반 식사→전통주→운전 예정 흐름을 확인했다. 실행별 합성 계정을 생성하고 삭제하며 외부 검색은 자동 실행하지 않는다. 결과 원문은 비공개 artifacts/verification/bartender/conversations-*.json에 보관한다.

- 공통 감각 어휘를 후보 목록과 별도로 제공해 단맛 제외가 사라지지 않게 한다.
- 가격 문의는 information으로 처리하며 새 추천 카드를 생성하지 않는다.
- 일반 식사는 food로 구분해 이전 술의 페어링 문맥에서 벗어나게 한다.
- 정형 감각에 해당하지 않는 현재 선호는 preferenceNotes에 보관한다. 향 강도를 향신료 향으로 치환하지 않는다.
- 수치 최저 도수는 명시된 사용자 입력에서 확인해 모델의 반올림/후보 도수 대입을 막는다.
- 조건 미충족은 drinkUnresolved에 보관해 후속 안주 대화에도 미확정 상태를 전달한다.
- 제외 감각이 제품 정보에 없다는 이유만으로 실제 부재가 입증되었다고 주장하지 않도록 설명한다.

일부 실행에서 상투적 표현/불필요한 되묻기와 서버 응답 실패가 관측됐다. 입력 보존과 동일 요청 재확인은 기존 UI 경로를 사용한다. 이번 검증은 대화 의미와 구조화 조건·후보를 함께 확인했으며 양 플랫폼 실기기 UI 검증과 구분한다.
