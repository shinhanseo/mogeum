# 로그인 문서 연결 · 2026-10-26

기존 로그인(Figma 04 / 4:3036, 저장된 login.json/login.svg)의 약관 안내 문구에 중첩 Text link 동작을 추가했다. 기존 문구·색·폰트·간격·줄바꿈은 바꾸지 않았다. 새로운 버튼이나 화면을 추가하지 않았다. URL이 미설정이면 기존 오류 안내 영역에 준비 중임을 알리며 외부 브라우저를 호출하지 않는다.

Expo가 인라인할 수 있도록 두 공개 환경 변수를 명시적으로 읽는다. 공개 HTTPS 문서만 허용하고 credential, localhost/IP, placeholder 및 다른 scheme은 차단한다. 외부 베타 gate도 같은 검증 함수를 사용한다. 브라우저 열기 오류는 복구 가능한 안내로 처리한다.

타입·린트·질문 계약, 전체 테스트 357개 중 349 통과·8 환경 의존 skip. 실제 게시 URL이 없어 해당 문서를 실제 기기에서 여는 검증과 최신 빌드 시각 비교는 미완료다. 테스트의 mogeum.app 주소는 문법 검증 fixture이며 실제 게시 주소라고 주장하지 않는다. 이 변경만으로 외부 배포 승인을 통과시키지 않는다.
