# 승인 앱 아이콘 적용 · 2026-11-01

사용자가 첨부해 확정한 크림 바탕/버건디 심볼 PNG를 `assets/brand/icon-master-approved.png`에 보관한다. 새 디자인을 추정해 그리지 않고 원본 전체를 비례 축소해 `icon.png`와 `adaptive-foreground.png`를 1024px로 내보낸다. SVG는 PNG 포함 export wrapper이며 편집 가능한 벡터 원본이 아니다.

`npm run beta:assets`가 기존 모구 아이콘으로 덮어쓰지 않도록 승인 원본을 읽게 수정했다. 모구 splash는 이번 아이콘 선택에 포함되지 않아 그대로 유지했다.

검증:
- 1024×1024 RGBA, alpha255 전체(불투명).
- 버건디 심볼의 중심 최대 반경311px로 Android adaptive safe radius341.3px 안에 들어감. 원형/rounded-square 마스크에 주요 심볼이 잘리지 않음.
- Android beta native prebuild 성공, iOS AppIcon 원본 갱신.
- npm run check 통과:462테스트 통과/14환경 제외.
- 이번 세션은 Device Hub의 iOS 버전 제한으로 아이폰 홈 화면 시각 검증은 불가. Release 빌드/설치는 별도로 보고함.
