# 홈·술장·취향 UI 개편 · 2026-10-29

사용자가 PNG 검토 후 Figma 전체 수정 없이 바로 개발하도록 명시했다. 이 개편은 04 Figma 원본 일치 작업이 아니라 채팅에서 승인한 새 시안의 구현이다. 기존 typography/colors를 재사용한다. Figma 파일은 수정하지 않았다.

- +의 음수 margin을 제거하고 68pt 행의 중앙에 48pt 기록 행동 배치. 홈/술장/+/내 취향/더보기로 분리하며 +는 탭이 아니다.
- 새 홈은 실제 개인 snapshot·추천·사진을 읽는 가로 pager와 최근2개 기록. snapshot이 읽는 동안 바뀌면 결과를 숨긴다. 계정 전환/화면 이탈/앱 background 응답은 epoch로 무시한다. 탭 진입 때 AI 생성은 호출하지 않는다. 추천 실패 시 임의 제품으로 채우지 않는다.
- 최근 기록은 마신 날짜 기준 최신2개다. 사진은 정사각형, 없으면 배경 없는 주종 일러스트. 태그는 기존 정규화된 답변에서만 가져온다. 메모로부터 임의 감각을 생성하지 않는다.
- 술장 사진/누끼 표시를 16종 벡터 대표 그림으로 교체. 기존 사진/누끼/기록 데이터는 삭제하지 않는다. 항목ID의 고정 hash로4개 변주 중 하나를 배정해 재실행/기기 간 동일하며 사용자 직접 선택은 아직 미구현이다. 실제 제품 외형을 뜻하지 않는다. 그림에는 흑맥주가 포함된다.
- 내 취향은 실제 감각 집계·좋게 남긴 기록/다른 평가 수·주종별 차이를 노출하고 기존 근거 경로 연결. 횟수를 정규화한 막대이며 한 칸당1잔인 고정8칸을 실제 데이터에 강제하지 않는다. AI 요약 기능도 별도로 유지한다.

타입/린트/전체 테스트433통과,환경14제외. 합성8잔의 취향 화면에서 7잔/다른 평가1잔의 막대·숫자 표시와 중앙 기록 버튼을 추가 확인했다. `ios-taste-fixture.png`는 개발용 합성 데이터만 포함한다. iOS26.5 시뮬레이터에서 새 홈 빈 상태와 기록 버튼/탭 표시 및 +의 중앙 배치를 확인했다. 채워진 실제 계정,작은 화면/큰 글자/Android와 네트워크 실패·로그인 전환의 새 화면 검증은 아직 남아 있다. 공개 배포·베타 설치 완료로 처리하지 않는다. 기존 서버 추천 개편과 이 UI 변경은 분리한다.

홈 사진 조회는 마신 날짜 기준 최근2개만 서명하며, 사진 조회/표시 실패는 일러스트로 대체한다. 술장 탭 진입 전에는 술장 페이지를 읽지 않으며 일러스트 개요는 개인 사진 서명·로컬 누끼 로딩을 생략한다. 기존 DB/RLS/API 계약으로 충분하여 이 UI 단계의 DB 마이그레이션은 추가하지 않았다. 추적: #198.

취향 개요 역시 사진을 표시하지 않으므로 개인 사진 URL 서명을 하지 않는다. 근거 상세의 기존 사진 로딩 경로는 유지한다. 현재 adb 장치 목록은 비어 있어 Android 실기기 검증은 수행하지 못했다.

## 추가 검증
- 작은 iPhone 시뮬레이터에서 취향 집계, 술장 필터 한 줄 표시, 중앙 +, 빈 술장과 기록2개 상태를 확인했다. `ios-small-empty.png`, `ios-small-two-records.png`는 합성 데이터다.
- 이름의 2줄 고정 빈 공간을 없애 주종 라벨 간격을 줄였다.
- AI 캐시가 stale이어도 현재 snapshot 집계는 계속 표시하고, 오래된 AI 선택만 숨긴다.
- `expo install --check` 통과. CI에서 요구한 Expo SDK58 패치 버전을 정렬했다. 네이티브 패키지 패치 변경 때문에 배포용 바이너리는 다시 빌드해야 한다.
- iOS/Android production JS·SVG 번들 export 성공. Android 에뮬레이터 실행·Metro 연결은 준비했지만 CUA에서 에뮬레이터 창에 연결하지 못해 시각 검증은 미완료다. Android UI 통과로 간주하지 않는다.

근거 연결 회귀 수정: 새 통계에서 세는 중립 평가도 근거 목록에 포함하고, AI 요약을 생성하지 않아도 전체 근거를 열 수 있게 했다. 주종별 느낌 선택은 해당 주종 필터를 초기 선택한다. 확정 전 답변·사진만 있는 기록은 감각 근거에서 계속 제외한다. 관련 테스트3개 추가 후 총436통과/14환경 제외다.

## 홈 점진 로딩 후속
최근 기록 context는 추천·사진 대기와 분리해 먼저 표시한다. 추천과 사진은 각각 실패할 수 있으며, 추천 hash가 현재 기록과 다르면 표시하지 않는다. 재검증 중 기록이 바뀌면 이전 홈을 숨기고 늦은 사진도 다시 살리지 않는다. 화면 이탈/계정 전환 시 loader generation을 취소한다. 추천 로딩/재시도 안내와 페이지 구성·화면 폭 변경 시 인디케이터 초기화를 추가했다. 관련5개 테스트 포함 총441통과/14환경 제외.

EAS의 PR199 소스(6eef1aa) Android code13 및 iOS simulator 순번10 빌드가 FINISHED다. 두 내장 번들 검사에서 알려진 서버키/개발probe 이슈0. iOS 작은 시뮬레이터에 설치 후 새 홈/술장/중앙+를 확인했다. 이 바이너리는 위 홈 점진 로딩 후속 변경을 포함하지 않는다. Android 설치 시 대상 emulator가 사라져 이번 설치는 미완료다.

홈 페이지 표시점을44pt 버튼으로 바꾸고 선택 상태·페이지 제목을 접근성 이름에 제공했다. 작은 iOS 개발용 앱에서2번째 표시점을 눌러 메뉴판 슬라이드와 선택 상태가 바뀌는 것을 확인했다(`ios-home-pager.png`).

## 큰 글자 후속 QA
작은 iPhone 시뮬레이터를 accessibility-large로 설정하고 개발 앱을 재실행했다. 홈 한글 제목의 단어 중간 줄바꿈, 바텀바 더보기의 두 줄 표시, 최근 기록 제목 옆 전체 보기의 가로 잘림을 확인해 보완했다. 제목은 iOS hangul-word/Android balanced 줄바꿈, 큰 글자(fontScale>1.3)의 섹션 제목·링크는 세로 배치다. 본문/주요 행동의 확대는 유지한다. 고정 아이콘 바의 짧은 탭 라벨만1.4배 상한과 한 줄을 적용하고, 점3개 아이콘은 문자 확대를 끈다(접근성 이름은 계정 관리). 확대 상태로 세로 스크롤해 전체 보기와 첫 기록 버튼 및 중앙+가 보이는 것을 확인했다. `ios-accessibility-home.png` 참고. 설정은 원래 large로 복구했다. Android 큰 글자는 아직 미검증이다. 타입/린트/테스트441통과/14환경 제외.

후속 CI가 Expo SDK58 요구 react-native0.88.1을 보고해 해당 패치와 lockfile을 맞췄다. 로컬 expo install --check 및441테스트가 통과했다. 패치 변경 이전 EAS Android14/iOS simulator11 빌드와 혼동하지 않는다.

## 긍정 평가가 없는 기록도 보여주기
괜찮아요/내 취향이 아니에요 평가만 있으면 이미 작성한 감각 대신 느낌 추가 안내로 돌아가던 상태를 보완했다. 긍정 근거가 있을 때는 기존 선호 집계를 유지하고, 없을 때는 작성한 관찰 감각과 전체 평가 수·근거 기록을 보여준다. 이를 선호로 부르거나 AI 긍정 요약으로 보내지 않는다. 사진만 있는 기록/미확정 노트는 계속 제외한다. 홈 안내도 감각 기록 유무에 맞춰 구분한다.

큰 글자에서는 취향 통계·감각 제목/숫자·AI 요약 제목/버튼·범례를 세로로 배치한다. 200개 제한으로 일부 기록이 빠지면 현재 분석 범위를 알린다. iOS 작은 화면에서 개발용 합성8개(긍정0개)의 관찰 집계와 근거 목록 표시, 요약 버튼 미노출을 확인했다(`ios-observations-only.png`). 실제 계정에 기록을 추가/수정하지 않았다. 큰 글자/Android의 이 화면 시각 QA는 별도 미완료다. 타입/린트/전체444통과/환경14제외.

### 취향 화면 큰 글자 추가 확인

iOS 26.5 작은 화면 시뮬레이터에서 Text Size 7로 관찰 전용 상태를 확인했다. 제목과 공통 버튼은 한글 단어 단위로 줄바꿈하며, 통계·수치·근거 링크는 세로 배치와 스크롤로 접근 가능했다. `ios-taste-large-text.png`는 합성 기록의 표시 QA이며 서버 저장/근거 이동 검증이 아니다. 확인 후 Text Size 3으로 복원했다. 전체 check: 444 pass, 14 환경 skip, 0 fail.

### 캐러셀 안내와 상세 배경 분리 진입 제거

사용자 승인: 다음 페이지 미리보기는 제외. 전체 너비 paging을 유지하고 페이지 수·다음/이전 안내와 스크롤 offset 기반 native Animated 점 확대를 추가했다. 자동 재생 없음, Reduce Motion에서는 점의 동적 확대 및 버튼의 부드러운 이동을 생략한다. 최근 노트 목록 유지. 추천에는 근거 기록 이름·닮은 특징·미확인 특징을 먼저 표시하며, 관찰 라벨을 취향 제목으로 단정하지 않는다. 기록 상세의 배경 분리 버튼만 제거하고 원본/누끼 데이터 및 기존 편집 경로는 삭제하지 않았다.

검사: 444 pass / 14 환경 skip / 0 fail. iOS 작은 화면 게스트 홈에서 점 버튼으로 1/2 → 2/2, 다음 → 이전 안내 전환 및 이웃 페이지 비노출 확인. `ios-home-carousel-controls.png`. 드래그 입력을 통한 연속 애니메이션의 부드러움, Android 터치, 실제 개인 추천이 채워진 홈은 이번 확인에 포함하지 않는다. 베타 15 이전 코드와 별도 수정이다.

### 홈 취향 슬라이드 · 기록 지표

기존 취향 화면과 같은 `tasteOverview` 집계를 재사용해 최대 3개 감각과 가는 막대를 홈 취향 슬라이드에 표시한다. 분모는 유효한 느낌 기록 수, 흰색은 좋게 남긴 기록, 회색은 다른 평가 기록이다. 빈 공간을 미입력=없음/비선호로 해석하지 않으며 임의 점수·퍼센트는 생성하지 않는다. 지표는 factId를 기존 `/taste-evidence` 경로에 전달한다. 메뉴판 슬라이드는 변경하지 않는다.

검증: 전체 check 444 pass / 14 환경 skip / 0 fail. 작은 iOS 시뮬레이터에서 5개 합성 기록의 4/1·3/0·1/1 분리 표시, 지표 클릭의 factId 전달 확인(`ios-home-taste-metrics.png`). 전체 neutral fixture의 positive0/관찰 문구 확인. 실제 계정 서버 저장·근거 화면 end-to-end·Android 표시 검증은 포함하지 않는다.

후속 디자인 조정: 가는 트랙 위 원형 포인트와 0잔/전체 기록 수 축을 적용했다. 조절 가능한 Slider가 아니라 근거 화면으로 이동하는 버튼이다. 기본 상태 포인트는 좋게 남긴 횟수, 관찰 전용 상태는 관찰 전체 횟수를 나타내며 아래 평가별 숫자는 유지한다. 0/100% 끝에서도 원이 잘리지 않게 6pt 내부 여백을 둔다. 전체 check 444 pass / 14 skip / 0 fail. `ios-home-taste-gauge.png`는 합성 시안이며 실제 계정 데이터가 아니다.
