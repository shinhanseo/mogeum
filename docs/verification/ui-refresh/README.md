# 홈·술장·취향 UI 개편 · 2026-10-29

사용자가 PNG 검토 후 Figma 전체 수정 없이 바로 개발하도록 명시했다. 이 개편은 04 Figma 원본 일치 작업이 아니라 채팅에서 승인한 새 시안의 구현이다. 기존 typography/colors를 재사용한다. Figma 파일은 수정하지 않았다.

- +의 음수 margin을 제거하고 68pt 행의 중앙에 48pt 기록 행동 배치. 홈/술장/+/내 취향/더보기로 분리하며 +는 탭이 아니다.
- 새 홈은 실제 개인 snapshot·추천·사진을 읽는 가로 pager와 최근2개 기록. snapshot이 읽는 동안 바뀌면 결과를 숨긴다. 계정 전환/화면 이탈/앱 background 응답은 epoch로 무시한다. 탭 진입 때 AI 생성은 호출하지 않는다. 추천 실패 시 임의 제품으로 채우지 않는다.
- 최근 기록은 마신 날짜 기준 최신2개다. 사진은 정사각형, 없으면 배경 없는 주종 일러스트. 태그는 기존 정규화된 답변에서만 가져온다. 메모로부터 임의 감각을 생성하지 않는다.
- 술장 사진/누끼 표시를 16종 벡터 대표 그림으로 교체. 기존 사진/누끼/기록 데이터는 삭제하지 않는다. 항목ID의 고정 hash로4개 변주 중 하나를 배정해 재실행/기기 간 동일하며 사용자 직접 선택은 아직 미구현이다. 실제 제품 외형을 뜻하지 않는다. 그림에는 흑맥주가 포함된다.
- 내 취향은 실제 감각 집계·좋게 남긴 기록/다른 평가 수·주종별 차이를 노출하고 기존 근거 경로 연결. 횟수를 정규화한 막대이며 한 칸당1잔인 고정8칸을 실제 데이터에 강제하지 않는다. AI 요약 기능도 별도로 유지한다.

타입/린트/전체 테스트433통과,환경14제외. 합성8잔의 취향 화면에서 7잔/다른 평가1잔의 막대·숫자 표시와 중앙 기록 버튼을 추가 확인했다. `ios-taste-fixture.png`는 개발용 합성 데이터만 포함한다. iOS26.5 시뮬레이터에서 새 홈 빈 상태와 기록 버튼/탭 표시 및 +의 중앙 배치를 확인했다. 채워진 실제 계정,작은 화면/큰 글자/Android와 네트워크 실패·로그인 전환의 새 화면 검증은 아직 남아 있다. 공개 배포·베타 설치 완료로 처리하지 않는다. 기존 서버 추천 개편과 이 UI 변경은 분리한다.

홈 사진 조회는 마신 날짜 기준 최근2개만 서명하며, 사진 조회/표시 실패는 일러스트로 대체한다. 술장 탭 진입 전에는 술장 페이지를 읽지 않으며 일러스트 개요는 개인 사진 서명·로컬 누끼 로딩을 생략한다. 기존 DB/RLS/API 계약으로 충분하여 이 UI 단계의 DB 마이그레이션은 추가하지 않았다. 추적: #198.
