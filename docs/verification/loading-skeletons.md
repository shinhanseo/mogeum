# 화면 로딩 스켈레톤

2026-11-05 — 사용자 요청에 따라 비동기 콘텐츠 로딩을 기존 디자인 토큰의 스켈레톤으로 표시한다. 기존 Figma에 없는 로딩 상태를 추가한 것으로, Figma 원본과 일치 검증한 화면은 아니다.

- 홈 추천 로딩 중 위스키·와인·맥주·전통주 4페이지를 먼저 확보한다. 기존 취향·메뉴판·바텐더와 합쳐 7페이지를 유지하다가 실제 결과로 교체한다. 추천 실패나 추천 가능한 데이터가 없는 경우 로딩을 종료하고 해당 안내를 표시한다.
- 추천 데이터 교체 시 캐러셀을 재마운트하지 않는다. 페이지 수가 줄어 현재 인덱스가 범위를 벗어나면 첫 페이지로 복귀한다.
- 술장 선반, 최근 기록·근거 목록, 상세 사진·노트, 기록 입력·복원, 테이스팅 질문, 취향 지표, 추천 목록, 메뉴판, 바텐더, 계정 인증 로딩에 각각 맞는 레이아웃을 제공한다.
- 오류·빈 상태와 로딩을 구분한다. 저장·삭제 등 행동 버튼의 기존 진행 표시는 유지한다.
- 로딩은 비대화형이며 스크린 리더에는 하나의 진행 상태로 전달한다. 시스템 동작 줄이기 설정을 존중하고 언마운트 시 애니메이션과 구독을 정리한다.

검증: npm run check 통과(481 통과, 외부 환경 필요한 14 건 skip). 최종 safe-area 보완 후 typecheck/lint 재확인. 기존 dev/carousel-height.tsx 중복 import 경고 2건은 남아 있다. iOS 26.5 시뮬레이터에서 개발용 미리보기로 술장·취향·홈 로딩 배치를 확인하고 헤더 safe area를 보완했다. Android 실기기에서 이번 로딩 UI를 직접 확인하지는 않았다. 화면 캡처는 로컬 artifacts/verification/loading-skeleton에 있으며 개발용 미리보기 라우트는 검증 후 삭제했다.
