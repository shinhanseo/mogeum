# 제품 조사 → 근거가 연결된 검토 후보 · #171

공유 호출 예약 안에서 검색1회 후 별도 structured extraction1회를 연결한다. 추가 추출은 검색 도구 없이 최대2000출력토큰·10초·재시도0이며 전체 파이프라인25초 signal을 공유한다. 예산의20/200은 파이프라인 시도 수로 한 시도에 최대2회 모델 호출을 포함한다. 실제 가격/검색 질의 수를 보장하는 금액 상한은 아니다. 신규 계약/모델 버전을 캐시 키에 넣어 기존 raw 검색 캐시와 분리한다.

추출 결과에는 제품명/판본의 인용문과 source/support index, 특징별 인용문과 동일 index를 보관한다. 특징 ID는 해당 주종의 기존 가벼운 질문에서 사용하는 정규화 감각 ID만 허용한다. 별도의 제품 ID·URL·가격·개인 선호·verified 플래그를 모델이 생성하지 못하게 한다. 검증은:

- 요청한 이름/판본이 정확히 같은 grounded 인용문에 등장해야 identity 후보가 된다. 번역명/모호한 판본은 임의 합치지 않고 identity null로 남긴다.
- 특징 인용문은 존재하는 support의 원문 부분 문자열이어야 하며, 해당 support에 연결된 source index여야 한다.
- 특징 출처는 identity 출처와 같아야 한다. 중복/없는 특징 ID·없는 인용/출처는 거부한다.
- 부정/가정/비교 단어가 들어간 segment는 보수적으로 거부한다. 긍정처럼 보이는 단어만 잘라 부정문을 뒤집지 않는다. 복잡한 언어 해석을 완전히 보장하는 검사가 아니다.
- 캐시에서 다시 읽을 때도 claims를 동일하게 검증한다. 추출 없는 identity null/특징0은 조작한 정보로 보충하지 않는다.

**이는 인용 연결과 형식 검증이며 실제 출처 페이지의 주장/정확한 판본/원저자 확인을 대체하지 않는다.** 모든 결과는 candidate에 머물며 검증된 공통 카탈로그에 자동 승격하지 않는다. 앱 추천에 직접 노출하지 않으며 사실 검증·출처 확인·검토 승격은 후속이다.

검증: 전체 단위423통과/환경12제외, 실제 SDK+fake HTTP transport의 추출 schema/추가 검색 없음/없는 인용 거부2/2통과. 기존 검색 SDK3/3통과, Deno service 타입 검사 통과. 실제 Gemini 호출·관리형 배포·새 후보의 실제 추천은 아직 미수행이다.
