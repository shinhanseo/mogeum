# iOS 1.0.1 업데이트 전 QA

## 이번 수정

- Expo 58 호환성 검사에서 실패하던 패키지 버전을 권장 범위로 정렬했다. 로컬 CocoaPods도 ExpoModulesCore/Worklets 및 safe-area-context를 갱신해 실제 Release 빌드로 확인했다. 생성된 ios 디렉터리는 Git에 포함하지 않는다.
- 사진 없이 작성하는 기록 화면 제목을 `사진 확인` 대신 `기록하기`로 표시한다.
- 추천 라우트의 인증 확인 중 빈 화면을 추천형 스켈레톤으로 교체한다.
- 홈 캐러셀에서 현재 페이지 외의 콘텐츠를 접근성 트리에서 숨긴다. 페이지 수 버튼은 계속 탐색할 수 있다.
- 이전 기록 비교 조회 실패 시 현재 기록/날짜별 목록은 유지하고 비교만 실패 안내를 제공하는 회귀 테스트를 추가했다.
- 합성 네이티브 probe는 전역 앱 세션에 로그인하지 않는 격리 클라이언트를 쓴다. 누끼 파일을 생성하지 않는 이 검사에서만 derivative 정리 포트를 no-op으로 주입해 실제 서버 사진 삭제를 검증했다. 제품 코드의 소유권 검증은 변경하지 않았다.
- 추천→기록→반복 노트 비교의 실제 HTTP 테스트를 CI에 추가했다.
- 기존 스토어 설정을 보존하고 버전 1.0.1로 준비했다. beta 식별자 없이 store-release 설정을 쓰면 실패시킨다. EAS remote version/autoIncrement는 유지한다.

## 배포 전 남는 실기기 확인

- 이번 작업에서 실제 Apple·카카오 계정 로그인 후 계정 삭제/제공자 연결 해제를 실행하지 않았다. 평소 쓰는 계정을 삭제하지 않는다. 로컬 Auth/삭제 테스트가 실제 제공자의 최종 해제 검증을 대체하지 않는다.
- iOS 편집→저장은 하드웨어 입력으로 확인했다. 실제 iPhone 소프트웨어 키보드의 높이 전환·Done 동작은 별도 확인이 필요하다.
- Android 실기기 연결이 없어 이번 변경의 실기기 터치/키보드 검증은 하지 않았다. 양 플랫폼 JS export 및 도메인 검사는 통과했다.
- 최신 기기용 개발 서명 Release 앱과 스토어 제출용 빌드는 구분한다. 스토어 1.0.1 제출은 EAS beta-store에서 새 빌드 번호로 만든 아카이브를 사용한다. 아직 심사 제출하지 않았다.
