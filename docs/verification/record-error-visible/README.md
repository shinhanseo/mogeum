# 기본 기록 실패 안내 가시성 · #144

저장 실패 문구는 접근성 트리에는 있지만 저장 버튼 뒤의 ScrollView 바닥에 추가되어 현재 viewport 밖에 남았습니다. iOS26.5에서 응답 중단 후 버튼만 다시 활성화되고 오류는 보이지 않는 상태를 재현했습니다. 새 오류가 렌더되면 다음 프레임에 ScrollView 끝으로 이동하도록 연결했습니다. 효과 정리 때 예약 프레임을 취소하며 오류가 없으면 이동하지 않습니다. 기존 문구·alert 역할·타이포·색·저장 버튼·pending 요청 계약은 유지합니다.
