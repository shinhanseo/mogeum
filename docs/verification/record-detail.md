# 기록 상세 연결 (2026-10-22)

Figma 04의 18(4:4171), 19(4:4227)에서 원본 치수를 추출했다. `figma-reference/detail.json`에 보존했다. 사진 폭 352/세로 469.33(3:4), 좌우 24, 제목 26, 본문 13, 고정 52 버튼을 네이티브 레이아웃으로 구현했다. 원본 전체 이미지를 UI로 사용하지 않는다.

술장 카드 → 해당 술의 최근 경험 상세. 날짜별 기록을 누르면 개별 record ID 상세로 이동한다. 기본 저장 및 노트 저장/닫기 후 해당 record ID 상세로 돌아온다. 노트 추가/수정은 기존 `/tasting`을 사용하므로 새로운 경험을 생성하지 않는다. 별점·재음용 의사·빈티지·확정 문장은 실제 저장값만 표시한다. 사진 URL 실패 시 중립 placeholder를 표시한다.

RLS에 더해 상세/이력 모두 현재 인증 사용자 ID로 범위를 좁힌다. 서버 키는 사용하지 않는다. 이력은 최근 100개까지 표시한다. 최신 기록 선택은 consumed_at 내림차순, 동률 id 순으로 안정적이다. 사진은 ready 중 sort_order 최소값에만 서명한다.
