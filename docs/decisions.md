# 확정 사항과 남은 결정

## 사용자와 합의한 기준

- 앱 이름: 모금. 타겟은 다양한 술을 즐기며 긴 기록은 부담스러운 사람.
- iOS·Android를 React Native로 함께 개발. 코드는 AI가 작성하고 사용자는 제품·실기기 검증 중심으로 참여.
- 사진만으로 기록 가능. 이름 자동 인식은 기록 MVP의 필수 기능이 아님.
- AI 취향 요약과 여러 장 메뉴판 분석은 출시 전 포함.
- 메뉴판은 최대 5장, 기기 OCR → 텍스트·좌표 → 서버 해석·추천 방향.
- 새로운 술도 출처 있는 맛 특징과 내 기록을 비교해 추천. 닮은 점과 다른 점·원본 위치 제공.
- 사진 없는 제품은 주종별 고정 SVG. 모구·아이보리·버건디 디자인 유지.
- GitHub 저장소는 public. 초기 문서·이슈 준비 요청이며 앱 구현은 아직 시작하지 않음.

## 기본 기술안

Expo Development Build/TypeScript/Expo Router, StyleSheet 토큰, TanStack Query/Zustand, Supabase Auth/Postgres/Private Storage/Edge Functions. 사용자 지시나 실제 호환성 검증에서 바뀌면 이유와 영향을 이 문서에 기록한다.

## 아직 확정하지 않은 것

| 결정 | 언제 확정 |
|---|---|
| 멘토의 정확한 일요일 마감 날짜 | 사용자 확인 후 milestones에 반영 |
| ONNX 또는 ML Kit와 모델·모듈·버전 | 실기기 OCR 비교 이슈 |
| AI provider/model·예산·한도 | 공통 AI 계약 및 평가 이슈 |
| Supabase/EAS 프로젝트·운영 region·bundle ID | 초기 설정과 계정 연결 |
| OAuth provider별 실제 설정 | 인증 구현. Figma 기본 Apple·카카오 |
| 술 제품 정보 초기 지원 범위·출처 수집 방식 | 카탈로그 이슈 |
| 실제 사진·모구 앱용 파일과 권리 범위 | 디자인 시스템/에셋 이슈 |
| 공개 소스 라이선스 | 소유자 결정. public이라는 이유로 MIT 등 임의 적용하지 않음 |

## 기술 선택 시 기록할 것

결정 날짜, 대안, 측정/공식 자료, 채택 이유, 영향 이슈, 되돌리는 조건. 기술 스택과 API 계약을 이슈마다 다르게 만들지 않는다. 성능 수치는 실측 전 추정으로 표시한다.
